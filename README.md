# DIGITALEMPIRE — 3D Business & City Building Simulation

Build a global corporate empire inside a living 3D WebGL metropolis.

## Features
- **3D Metropolis (Three.js + WebGL)**: Dynamic day/night cycle, weather (clear, overcast, rain, fog), animated instanced traffic & pedestrians, harbor cargo ship, airport runway & aircraft, smoke particles, RoomEnvironment PBR reflections, and 48 interactive city plots.
- **Construction & Customization**: 12 composite multi-part procedural buildings with animated tower cranes during construction, 5 upgrade levels, 90° rotation, and fair cosmetic skins.
- **10 Industries & Dynamic Economy**: Found multiple companies, set selling price multipliers, hire & train staff and managers, and react to live supply/demand commodity prices, taxes, energy balance, and economic cycles.
- **9-Branch Research Tree**: Unlock advanced facilities and empire-wide efficiency bonuses.
- **Real-Time Multiplayer (WebSockets)**: Live online player presence, visit other players' 3D empires, P2P trade contracts, alliances with joint megaprojects, and global leaderboard.
- **Bilingual UI (DE / EN)**: 14 functional menus in a low-occlusion HUD with collapsible bottom control dock and procedural Web Audio synthesizer.

## Scripts
- `npm run dev` — Start development server (`server.ts` on port 3000 with Vite middleware + WebSockets)
- `npm run build` — Build production client bundle (`dist/`)
- `npm start` — Run production Node.js server
